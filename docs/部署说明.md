# 民宿预订与房态管理系统部署说明

## 一、部署环境

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11、Linux 或 macOS |
| JDK | JDK 17 或更高版本 |
| Maven | Maven 3.9+，也可使用项目自带 Maven Wrapper |
| 数据库 | 默认 H2，不需要单独安装；也可切换 MySQL 8 |
| 默认端口 | 8080 |
| 浏览器 | Edge、Chrome、Firefox 等现代浏览器 |

项目使用 Spring Boot 内置 Tomcat，打包结果为可执行 JAR，不需要单独安装 Tomcat。

## 二、IDEA 本地部署

### 1. 导入项目

打开 IntelliJ IDEA，选择 `File → Open`，打开项目源码目录：

```text
homestay-management
```

如果 IDEA 没有自动识别 Maven，右键 `pom.xml`，选择 `Add as Maven Project`，然后在 Maven 面板中点击刷新。

### 2. 配置 JDK

打开 `File → Project Structure → Project`：

```text
SDK：JDK 17
Language level：17
```

### 3. 启动项目

打开启动类：

```text
src/main/java/com/example/homestay/HomestayManagementApplication.java
```

点击类名旁边的绿色运行按钮，选择：

```text
Run 'HomestayManagementApplication.main()'
```

控制台出现以下信息表示启动成功：

```text
Tomcat started on port 8080 (http)
Started HomestayManagementApplication
```

浏览器访问：

```text
http://localhost:8080
```

演示账号：

```text
账号：admin
密码：123456
```

## 三、可执行 JAR 部署

### 1. 打包

在项目根目录执行：

```bash
./mvnw clean package
```

Windows 使用：

```powershell
.\mvnw.cmd clean package
```

打包成功后生成：

```text
target/homestay-management-1.0.0.jar
```

### 2. 运行

Windows：

```powershell
java -jar target\homestay-management-1.0.0.jar
```

Linux：

```bash
java -jar target/homestay-management-1.0.0.jar
```

启动完成后访问：

```text
http://服务器IP:8080
```

### 3. 指定端口

如果 8080 端口已被占用，可以临时修改端口：

```bash
java -jar target/homestay-management-1.0.0.jar --server.port=8081
```

此时访问地址为：

```text
http://localhost:8081
```

## 四、Linux 服务器部署

### 1. 上传文件

将以下文件上传到服务器，例如 `/opt/homestay`：

```text
homestay-management-1.0.0.jar
```

### 2. 后台启动

```bash
cd /opt/homestay
nohup java -jar homestay-management-1.0.0.jar > app.log 2>&1 &
```

查看日志：

```bash
tail -f app.log
```

### 3. 停止服务

查找 Java 进程：

```bash
ps -ef | grep homestay-management
```

停止进程：

```bash
kill 进程号
```

### 4. 开放端口

以常见 Linux 防火墙为例：

```bash
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload
```

如果使用云服务器，还需要在云平台安全组中开放 `8080` 端口。

## 五、数据库部署

### 1. H2 数据库

项目默认使用文件型 H2 数据库：

```text
jdbc:h2:file:./data/homestay;MODE=MySQL;AUTO_SERVER=TRUE
```

第一次启动会自动建表并写入演示数据。数据库文件位于运行目录的：

```text
data/homestay.mv.db
```

H2 控制台：

```text
http://localhost:8080/h2-console
```

连接参数：

```text
JDBC URL：jdbc:h2:file:./data/homestay
用户名：sa
密码：空
```

### 2. 切换 MySQL

创建数据库：

```sql
CREATE DATABASE homestay_management
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

修改：

```text
src/main/resources/application-mysql.yml
```

配置 MySQL 用户名和密码，然后使用 `mysql` 配置启动：

```bash
java -jar homestay-management-1.0.0.jar --spring.profiles.active=mysql
```

也可以直接在启动命令中覆盖连接参数：

```bash
java -jar homestay-management-1.0.0.jar \
  --spring.profiles.active=mysql \
  --spring.datasource.url="jdbc:mysql://127.0.0.1:3306/homestay_management?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai" \
  --spring.datasource.username=root \
  --spring.datasource.password=你的密码
```

第一次启动会自动创建数据表并初始化演示数据。

```text
http://localhost:8080/api/health
```

正常返回示例：

```json
{
  "status": "UP",
  "application": "民宿预订与房态管理系统",
  "time": "2026-10-29T12:00:00"
}
```

建议依次检查：

- `http://localhost:8080/homestays`：门店房源

- `http://localhost:8080/orders`：订单中心
- `http://localhost:8080/reviews`：住客评价

## 七、常见问题

### 1. 端口被占用

报错：

```text
Port 8080 was already in use
```

解决方法：

```bash
java -jar homestay-management-1.0.0.jar --server.port=8081
```

### 2. 浏览器显示连接被拒绝

先确认控制台已经出现：

```text
Started HomestayManagementApplication
```

再访问：

```text
http://localhost:8080
```

不要只输入 `localhost`，需要包含端口 `:8080`。

### 3. 提示找不到 Java

执行：

```bash
java -version
```

如果命令不存在，需要安装 JDK 17 或更高版本，并配置 `JAVA_HOME` 和 `PATH`。

### 4. H2 数据库文件被占用

确认没有同时运行多个应用实例。停止其他 Java 进程后重新启动。

### 5. 页面图片或样式不显示

重新执行 Maven 打包，确认 JAR 内包含：

```text
BOOT-INF/classes/static
BOOT-INF/classes/templates
```

## 八、生产部署说明

本项目用于课程演示。正式部署时还应完成：

- 将管理员密码从配置文件迁移到安全的环境变量
- 使用 Spring Security 和密码哈希
- 关闭或限制 H2 控制台
- 配置 HTTPS
- 配置数据库备份
- 使用 Nginx 或其他反向代理
- 使用 systemd、Docker 等方式管理常驻进程
